Backup and sharing

Export the household ledger to a JSON backup and import it on your spouse's phone. Exporting includes receipt photos, so backups can be large. Keep backups somewhere private.

For sharing: export from one phone, send the file privately, then import it on the other phone. Avoid editing both copies independently, because this starter version does not automatically merge changes.

Settings

Data and privacy

This app stores expenses in this browser on this device. It does not send your records to a server. Browser storage can be removed by device/browser cleanup, so export backups regularly. Receipt images are stored inside the local database and can increase its size.

Shared use is currently backup-based, not live synchronization. For two phones, import the latest shared backup on the device that needs the updated ledger.
